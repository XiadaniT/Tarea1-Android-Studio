1. DESCRIPCIÓN DE LA APP
------------------------
Esta aplicación es un proyecto base desarrollado en Android Studio utilizando 
Kotlin/Java. La app está estructurada mediante el uso de Fragments para 
gestionar diferentes vistas de manera dinámica.

La aplicación incluye:
* Pantalla principal de navegación (BotonesActivity).
* Secciones interactivas divididas en:
    - Fragmentos de Botones (1 al 5): Control de eventos y navegación.
    - Fragmentos de Información (1 al 5): Visualización de datos estáticos.
    - Fragmentos de Listas (1 al 5): Manejo de colecciones de datos.
    - Fragmentos de Selección y Texto: Interacción con el usuario.

El objetivo de la app es demostrar el dominio en la transición entre 
fragmentos y la organización de componentes dentro de una misma Activity.

2. INSTRUCCIONES DE USO
-----------------------
Para ejecutar y probar la aplicación, sigue estos pasos:

A. Clonar o Descargar:
   Descarga el código desde este repositorio o clónalo usando Git.

B. Abrir en Android Studio:
   1. Abre Android Studio.
   2. Ve a File -> Open.
   3. Selecciona la carpeta "Tarea1".

C. Compilación:
   1. Espera a que el sistema Gradle sincronice todas las dependencias.
   2. Conecta un dispositivo físico o inicia un Emulador (AVD).
   3. Haz clic en el botón "Run" (icono de triángulo verde).

D. Navegación en la App:
   - Al iniciar, verás la "BotonesActivity".
   - Utiliza los controles en pantalla para intercambiar entre los diferentes 
     Fragments de información, listas y selección.
